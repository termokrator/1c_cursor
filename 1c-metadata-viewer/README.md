# 1С: Дерево метаданных

Расширение для Cursor/VS Code, отображающее структуру метаданных 1С в виде дерева на основе файлов выгруженной конфигурации.

## Установка

### Вариант 1: Установка как локальное расширение

1. Скопируйте папку `1c-metadata-viewer` в каталог расширений Cursor:
   - **macOS:** `~/.cursor/extensions/`
   - **Windows:** `%USERPROFILE%\.cursor\extensions\`
   - **Linux:** `~/.cursor/extensions/`

2. Перезапустите Cursor.

### Вариант 2: Запуск в режиме разработки

1. Откройте папку `1c-metadata-viewer` в Cursor.
2. Нажмите **F5** или выберите **Run > Start Debugging**.
3. Откроется новое окно Cursor с загруженным расширением.
4. В новом окне откройте папку с конфигурацией 1С (содержащую `Configuration.xml`).

## Использование

1. Откройте проект с выгруженной конфигурацией 1С.
2. В боковой панели проводника найдите раздел **«1С Метаданные»**.
3. Разверните дерево — структура отображается в порядке, привычном для конфигуратора 1С:
   - Справочники
   - Документы
   - Обработки
   - Перечисления
   - и т.д.
4. Щёлкните по элементу, чтобы открыть соответствующий файл.

## Обновление дерева

Нажмите кнопку обновления (↻) в заголовке панели «1С Метаданные» или выполните команду **«Обновить дерево метаданных»** из палитры команд (Cmd+Shift+P).

## Требования

- Cursor или VS Code 1.74+
- Проект должен содержать файл `Configuration.xml` в корне (выгруженная конфигурация 1С в формате XML)
